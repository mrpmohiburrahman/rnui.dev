## Method

Compare each candidate implementation path with every Recording source.
Ignore the branch or commit segment. Keep the owner, repository, and path.
A path match is exact when one path equals the other or one path contains the other as a folder.
A repository-root source is not an exact folder match.
Caption matches use the catalogue caption string, copied without a case change in the pair table.
Weak name overlap, such as pie chart against bar chart, stays in the new class.
