### Phase 3 — Codex Proof-of-Concept (est. 8–12 h, the heart of the application)

**Goal:** Demonstrate that Codex is integrated into the project's actual workflow, not just mentioned in a README.

The Vercel AI SDK (`ai`, `@ai-sdk/openai`) is already installed but unused. Wire it up.

**Deliverable 3a — `scripts/codex-ingest.ts`:**

- Input: a GitHub URL, Expo Snack URL, or gist URL passed as `npm run codex:ingest -- <url>`.
- Flow:
  1. Fetch the page (or `gh api` for GitHub repos) to get README, package.json, demo screenshots.
  2. Call OpenAI via `@ai-sdk/openai` (model: `gpt-5-codex` if available, else `gpt-4o-mini` as fallback) with a structured-output schema requesting `{ title, author, category, description, tags, repoUrl, socialIds: { twitter?, github? } }`.
  3. Validate output with Zod against the catalog schema (derive the schema from the existing `data/*.ts` shapes).
  4. Delegate thumbnail generation to the existing `scripts/generateThumbnails.ts` pipeline.
  5. Append the new entry to `data/<category>.ts` using AST-safe insertion (prefer `ts-morph`) so existing formatting is preserved.
  6. Create a branch `submission/<slug>`, commit, push, open a PR via `gh pr create` with a body templated from the AI's description.

**Deliverable 3b — `.github/workflows/codex-triage.yml`:**

- Trigger: `pull_request: [opened, synchronize]`.
- Steps: checkout, install, run `scripts/codex-review-pr.ts` which:
  1. Reads the PR diff (`gh pr diff $PR`).
  2. Sends it to Codex with a rubric (schema compliance, no duplicate IDs, image asset present, description quality).
  3. Posts a review via `gh pr review --comment -b "$REVIEW"`.
  4. Adds labels: `ready`, `needs-thumbnail`, or `spam`.
- Requires `OPENAI_API_KEY` secret on the repo.

**Deliverable 3c — `scripts/codex-search-index.ts`:**

- Reads every entry across `data/*.ts`.
- Calls `openai.embeddings.create({ model: "text-embedding-3-small", input })` per entry.
- Upserts into a `catalog_embeddings` Supabase table (pgvector column `embedding vector(1536)`).
- Includes a `supabase/migrations/<timestamp>_catalog_embeddings.sql` migration.

**Deliverable 3d — `app/api/search/route.ts`:**

- `POST /api/search` accepts `{ q: string }`.
- Embeds the query, runs a pgvector cosine search against `catalog_embeddings`, returns top 20 entries hydrated with full metadata.

**Deliverable 3e — `app/search/page.tsx`:**

- Client component with a search input.
- Streams results from `/api/search` using the Vercel AI SDK's `useChat` / `streamText` patterns (whichever fits — it's a one-shot, not a chat, so a plain `fetch` may be simpler and is acceptable).

**Acceptance:** Each script runs successfully on the user's machine against at least one real URL. `npm run codex:index` populates Supabase. Visiting `localhost:3000/search` and typing "swipeable card animation" returns ranked, relevant results.

React Native devs spend hours hunting for animation references across Twitter threads, gists, Snacks, and GitHub repos. `rnui.dev` centralizes them with reproducible source links, attribution, and natural-language search.

## What's inside

- **343+ animations** across Reanimated, Skia, Moti, Gesture Handler, and Lottie.
- **Natural-language search** powered by OpenAI embeddings + Supabase pgvector.
- **AI-assisted submissions**: drop a GitHub URL, Codex extracts metadata and opens a PR.

This project uses OpenAI Codex in three places:

1. `scripts/codex-ingest.ts` — turns a GitHub/Snack/gist URL into a schema-valid catalog entry and PR.
2. `.github/workflows/codex-triage.yml` — reviews every submission PR.
3. `scripts/codex-search-index.ts` + `app/api/search/route.ts` — RAG search over the catalog.

### `scripts/codex-ingest.ts` (skeleton)

```ts
/**
 * Usage: npm run codex:ingest -- <github-url|snack-url|gist-url>

 * Pipeline:
 *  1. Fetch source metadata.
 *  2. Ask Codex to extract a catalog entry (structured output).

 *  4. Generate thumbnail (delegates to scripts/generateThumbnails.ts).

 *  6. Branch + commit + open PR via gh.
 */

import { execSync } from "node:child_process";
import { generateObject } from "ai";
import { openai } from "@ai-sdk/openai";
import { z } from "zod";
import { Project, SyntaxKind } from "ts-morph";

const url = process.argv[2];
if (!url) {
  console.error("Usage: npm run codex:ingest -- <url>");

const EntrySchema = z.object({
  id: z.string().regex(/^[a-z0-9-]+$/),
  title: z.string().min(3).max(80),
  author: z.string(),
  category: z.enum(["reanimated", "skia", "moti", "gesture-handler", "lottie", "other"]),
  description: z.string().min(20).max(400),
  tags: z.array(z.string()).min(1).max(8),
  repoUrl: z.string().url(),
  socialIds: z
    .object({ twitter: z.string().optional(), github: z.string().optional() })
    .optional(),
});

async function fetchSource(url: string): Promise<{ readme: string; meta: Record<string, unknown> }> {
  if (url.includes("github.com")) {
    const match = url.match(/github\.com\/([^/]+)\/([^/]+)/);
    if (!match) throw new Error(`Bad GitHub URL: ${url}`);
    const [, owner, repo] = match;
    const readme = execSync(`gh api repos/${owner}/${repo}/readme --jq .content`, { encoding: "utf8" });
    const meta = JSON.parse(execSync(`gh api repos/${owner}/${repo}`, { encoding: "utf8" }));
    return { readme: Buffer.from(readme.trim(), "base64").toString("utf8"), meta };
  }
  // TODO: Snack + gist fetchers — implement before submission.
  throw new Error(`Unsupported source: ${url}`);
}

async function main() {
  const { readme, meta } = await fetchSource(url);

  const { object: entry } = await generateObject({
    model: openai("gpt-4o-mini"), // swap to gpt-5-codex when available
    schema: EntrySchema,
    prompt: `You are cataloging a React Native animation/UI project for rnui.dev.
Source URL: ${url}
Repo metadata: ${JSON.stringify(meta, null, 2).slice(0, 2000)}
README:
${readme.slice(0, 8000)}

Extract a catalog entry. Choose the most specific category. The "id" must be kebab-case and unique-looking.`,
  });

  console.log("Codex extracted:", entry);

  // Append via ts-morph
  const project = new Project({ tsConfigFilePath: "tsconfig.json" });
  const sourceFile = project.addSourceFileAtPath(`data/${entry.category}.ts`);
  const arr = sourceFile.getVariableDeclarationOrThrow((d) => d.getInitializerIfKind(SyntaxKind.ArrayLiteralExpression) !== undefined);
  const init = arr.getInitializerIfKindOrThrow(SyntaxKind.ArrayLiteralExpression);
  init.addElement(JSON.stringify(entry, null, 2));
  await sourceFile.save();

  // Thumbnail (delegate)
  execSync(`npx tsx scripts/generateThumbnails.ts --only ${entry.id}`, { stdio: "inherit" });

  // Branch, commit, PR
  const branch = `submission/${entry.id}`;
  execSync(`git checkout -b ${branch}`, { stdio: "inherit" });
  execSync(`git add data/${entry.category}.ts public/thumbnails`, { stdio: "inherit" });
  execSync(`git commit -m "feat: add ${entry.title}"`, { stdio: "inherit" });
  execSync(`git push -u origin ${branch}`, { stdio: "inherit" });
  execSync(
    `gh pr create --title "Add ${entry.title}" --body "Automated submission via codex-ingest.\n\nSource: ${url}\n\n${entry.description}"`,
    { stdio: "inherit" },
  );
}

main().catch((err) => {
  console.error(err);
  process.exit(1);
});
```
