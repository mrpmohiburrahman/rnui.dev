# Sponsor candidate shortlist

Research date: 2026-11-07.

This file is the single canonical sponsor list. Every other file that names sponsor candidates only gists this list and links here. Do not keep a second list elsewhere.

This shortlist is for selection. It is not an outreach list that authorizes email writing.

## Selection rules

- React Native and mobile fit ranks first.
- A specific commercial product ranks above a free project with no paid offer.
- A verified history of relevant sponsorship is stronger than general marketing activity.
- Service companies sit in their own tier.
- Adjacent developer tools sit below mobile and React Native candidates.
- Every contact path must come from an official public source.
- A suggested offer is a starting point. It does not reserve inventory.
- An exclusive offer blocks every other sponsor for the same month. Stop offering it after one acceptance.
- Split offers need explicit slot and date assignments. Never sell the same slot twice.

## Offer key

- **Exclusive:** one sitewide sponsor. List $499 per month. Founding price $249 per month for the first two sponsors.
- **Native demo:** one sponsored demo tile. $249 per month alone. $399 per month with the native bundle.
- **Split:** one defined placement from $79 to $199 per month.

See [Sponsor pricing](pricing.md) for the evidence and constraints.

### Match the product to the offer

- A visual UI, animation, or app-builder product starts with the native demo.
- A React Native platform, backend, payment, or analytics product starts with the exclusive offer or the top strip.
- A CI/CD, testing, or release product starts with the top strip or the recording-detail card.
- A consultancy starts with the exclusive offer or the recording-detail card.
- An adjacent developer tool starts with the products-page banner as a lower-cost relevance test.

The suggested offer never changes the verified impression count.

- [**Mobot**](https://www.mobot.io/) and [**Sauce Labs**](https://saucelabs.com/): deferred behind candidates with clearer current RN integration.
- **Previous advertisers:** past spending does not prove current budget or interest.

- **Free SDKs and free tiers:** identify the paid hosted service or subscription in every campaign.
