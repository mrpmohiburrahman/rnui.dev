## Tweet 2 (thread reply — how to contribute)

Want to add your animation to the catalog?

Just run:
```
npm run codex:ingest -- <your-github-url>
```

Codex extracts the metadata, validates against the schema, and opens a PR automatically. No YAML editing required.
